# 8번 출구 (The Exit 8) - 세이브 완전 초기화 & 즉시 8번 출구 치트 모드
**Exit8 MasterMod (v2.5 - UMG Anomaly HUD & Auto-Sustaining Exit 8)**

## 0. v2.5 변경 사항

* **HUD 미표시 버그 수정**: Shipping 빌드에서는 `PrintString` 화면 출력이 컴파일 제외되어 있고, 게임 HUD 가 BP 에서 `ReceiveDrawHUD` 를 구현하지 않아 캔버스 훅도 호출되지 않았습니다. HUD 를 UMG 위젯(`UserWidget` + `WidgetTree`)으로 런타임에 직접 만들어 뷰포트에 붙이는 방식으로 교체했습니다. 게임의 한글 폰트(`KoreanGD-H_Font`)를 자동으로 찾아 사용합니다.
* **이변 감지 정확도 개선**: `BP_ChangeManager_C.Change` 플래그를 기준으로 판단합니다. `CurrentChangeActor`/`CurrentChangeTag` 는 이변이 없어도 이전 값이 남아 있어서 이것만으로 판단하면 정상 복도를 이변으로 오인했습니다. 0번/8번 복도에서도 이변이 있으면 표시합니다.
* **리팩토링**: 한 파일(약 900줄)이던 `main.lua` 를 `exit8/` 폴더의 모듈(util / game / anomaly_db / tracker / hud)로 분리했습니다.
* **성능**: 매 틱마다 5~7번씩 하던 `FindAllOf` 전체 오브젝트 탐색을 캐시해서, 약 1초에 한 번 또는 오브젝트가 사라졌을 때만 다시 탐색합니다.

## 1. 0, 2, 4, 6, 8 버그 원인 분석

* **버그 증상**: `F8` 키를 1번 누를 때마다 표지판 숫자가 2씩 증가(0 → 2 → 4 → 6 → 8)하여, 총 4번을 연타해야만 8번 출구가 되던 현상.
* **원인 규명**:
  1. 무한 루프 통로 구조상 레벨에는 **2개의 통로 액터(`Path[1]`, `Path[2]`)가 상시 존재**합니다.
  2. 치트 함수 내부에서 층 번호 동기화를 위해 호출했던 블루프린트 함수 `path:NextPathNumber()`는 숫자를 강제 설정하는 함수가 아니라, **"다음 통로 번호로 +1 증가"**시키는 함수였습니다.
  3. `for idx, path in ipairs(allPaths)` 루프가 2개의 통로 액터를 순회하면서:
     * `Path[1]`에서 `NextPathNumber` 실행 → 번호 +1
     * `Path[2]`에서 `NextPathNumber` 실행 → 번호 +1
     * **1번 키를 누를 때마다 +2씩 가산 (0 → 2 → 4 → 6 → 8)**
  4. 따라서 8번에 도달하기까지 정확히 4번의 키 입력이 필요했던 것입니다.
* **해결책**:
  * 점진적 증가를 유발하던 `NextPathNumber()` 호출을 완전히 제거.
  * 모든 통로 액터와 출구 액터에 `Number = 8` 및 표지판 숫자를 **단 1회의 키 입력으로 즉시 강제 확정(Idempotent Direct Assign)**하도록 수정.

## 2. 모드 주요 기능

### [기능 1] 단 1회 입력으로 즉시 8번 출구 전환 (1-Press Instant Exit 8)
* **단축키**: **`F8`** 또는 키보드 숫자 **`8`**
* **이제 4번 누를 필요 없이, 단 1번만 누르면 즉시 8번 출구로 바뀝니다!**
  * 현재 통로와 연결 통로 전체가 즉시 '8'로 고정됩니다.
  * 지상 탈출 복도(`BP_Exit`)가 즉시 개방되며, 천장 표지판도 '8'로 유지됩니다.
  * 통로 내의 모든 이변이 즉시 소멸(`SetNoChange`)되어 깨끗한 8번 출구 상태로 탈출할 수 있습니다.

### [기능 2] 키 입력 없는 자동 세이브/해금 완전 초기화 (Auto Full Reset)
* 게임 실행 시 자동으로 발동되어 세이브를 순정 새 게임(0% 진행) 상태로 유지합니다:
  * `Clear = false`, `AllAno = false`, `EndTutorial = false`
  * 벽면 포스터가 정상적으로 **"남은 이변: 35개"**를 표시합니다.

### [기능 3] 통로 표지판 증발 방지 및 무(無)이변 가디언
* 치트 발동 시나 통로 전환 시에도 천장 노란색 출구 표지판(`Sign`)이 사라지지 않고 유지됩니다.
* 8번 출구 활성화 상태에서는 어떠한 이상현상도 나타나지 않도록 상시 차단합니다.

### [기능 4] 수동 세이브 완전 초기화 단축키
* **단축키**: **`F7`**
* 플레이 도중 언제든 누르면 세이브 파일과 모든 진행 상태를 새 게임 상태로 즉시 다시 리셋합니다.

### [기능 5] 화면 좌측 상단 이상현상 실시간 HUD 감지 & 알림 (Real-time Anomaly Tracker)
* **단축키**: **`F9`** (HUD On/Off 토글)
* **UMG 오버레이 위젯**: 화면 왼쪽 위에 반투명 박스 + 상태 색상 바 + 두 줄 안내로 표시됩니다. 위치/글자 크기/언어는 `config.lua` 의 `HUD_*` 항목으로 바꿀 수 있습니다.
* **모든 복도 상시 표시**: 게임 시작 직후 **0번 시작 복도부터 8번 출구까지** 상시 표시됩니다.
* **이상현상 실시간 감지**: 기본 150ms 주기로 이변 관리자 상태를 읽어 화면에 안내하며, 새 이변이 감지되면 약 2초간 **`[★ 신규 이변 스폰! ★]`** 배너가 강조됩니다.
  * 🔵 **0번 복도 (시작 복도)**: `[출구 #0] 0번 시작 복도 (이상현상 없음) >> 안전합니다. 앞으로 계속 직진하세요!`
  * 🟠 **이상현상 감지 시**: `[출구 #N] [★ 신규 이변 스폰! ★] 열려있는 문 >> [이상현상 감지] 즉시 뒤로 돌아가세요! (U턴)`
  * 🔴 **치명적 이변 시**: `[출구 #N] [이상현상 감지] ★ 붉은 홍수(바다) 밀려옴! ★ >> [긴급 경보] 치명적 이변! 즉시 뒤로 도망치세요! (U턴)`
  * 🔵 **이상현상 없을 시**: `[출구 #N] 이상현상 없음 (정상 복도) >> 안전합니다. 앞으로 계속 직진하세요!`
  * 🟢 **8번 출구 도달 시**: `[출구 #8] ★ 8번 출구 도달 (지상 통로) ★ >> 탈출 성공! 앞의 계단으로 나가세요!`
* 한글이 네모(□)로 깨지면 `UE4SS.log` 의 `Loaded fonts` 목록을 보고 `HUD_FontHints` 에 키워드를 추가하세요.
